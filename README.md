# Digital Certificate Verification System

## Project Description
Educational certificates are often verified manually, which takes more time. This project provides a web application where certificates can be uploaded, securely stored, and verified using a unique certificate ID.

## Technology Stack
- Frontend: React.js, Bootstrap, React Icons, Axios
- Backend: Node.js, Express.js, Multer
- Database: MongoDB with Mongoose
- Storage: Local uploads folder for development

## Main Modules
1. Dashboard
2. Certificate Upload
3. Unique Certificate ID Generation
4. Public Certificate Verification
5. Certificate Records & Search
6. Certificate Revocation
7. Original Certificate Preview

See `frontend/README.md` for complete setup instructions.
